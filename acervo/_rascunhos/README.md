# Rascunhos do acervo

Blocos em revisão técnica. O sistema **não** carrega esta pasta: só as pastas
diretamente dentro de `acervo/` viram blocos.

Para publicar um bloco depois da revisão:

1. Corrija as fichas e preencha as referências e o "Revisado por".
2. Preencha `homologado_em` no `bloco.toml`.
3. Mova a pasta para `acervo/<bloco>/` e rode `ipeia verificar`.

As fichas foram redigidas com palavras próprias a partir de conhecimento técnico
geral, sem reproduzir texto de livros. Elas não têm doses de medicamentos.
**São rascunhos: podem conter erros e precisam da revisão de um Engenheiro de
Pesca ou Médico Veterinário antes de ir a campo.**
